# band-strobe · spec.json 字段

> 时间单位：`duration` 是秒，其余全是**帧**（按 `fps` 换算）。
> 用帧不用秒是有原因的：0.1s 在 60fps 下是 6 帧，写成秒再换算会在取整上抖。

## 顶层

| 字段 | 必填 | 缺省 | 说明 |
|---|---|---|---|
| `id` | | — | 只作标识，脚本不用它命名产物（落点由 `--out` 决定） |
| `width` / `height` | | 1920 / 1080 | 画幅。MUST 等于目标工程画幅 |
| `fps` | | 60 | 帧率。**频闪技法建议 ≥ 50**——30fps 下 6 帧就是 0.2s，快不起来 |
| `duration` | ✓ | — | 产物时长（秒）。等于坑位长度即可，不必像颗粒那样留余量（视频没有"驻留"问题） |
| `bands` | | 3 | 整数 = 等分 N 条；数组 = 各带高度，**合计 MUST == `height`** |
| `clips` | ✓ | — | 素材路径数组（相对 spec 文件或绝对）。**数量 MUST ≥ 带数 + 1** |
| `rhythm` | | 见下 | 节奏 |
| `source` | | 见下 | 从每个素材的哪一段取材 |
| `grade` | | 见下 | 调色与故障化 |
| `seed` | | 0 | 随机种子。同 seed 同 spec ⇒ 逐帧一致，可复现 |
| `crf` | | 16 | x264 质量。频闪片高频细节多，别高于 20 |

## `rhythm`

| 字段 | 缺省 | 说明 |
|---|---|---|
| `mode` | `uniform` | `uniform` 等间隔快闪 / `rhythm` 慢段与急闪串交替 |

### `mode: "uniform"`

| 字段 | 缺省 | 说明 |
|---|---|---|
| `seg` | 6 | 每张停留帧数。4 极快 / **6 推荐** / 8 还能看清 / 12 已不算频闪 |
| `phase` | 自动 | 各带的相位偏移（帧），长度 == 带数。自动值把 `seg` 均分给各带 |

> 🔴 `uniform` 档下 **MUST NOT** 再让段长随机——等间隔的价值就是不匀速的反面。
> 各带的区分靠 `phase`，不靠段长。

### `mode: "rhythm"`

| 字段 | 缺省 | 说明 |
|---|---|---|
| `hold_pool` | `[16,17,22,26,26,27,27,28,39,39,39,43,43]` | 慢档段长池（帧），按**经验分布**采样 |
| `burst_pool` | `[3,4,5,5,5,5,5,6,7,7]` | 快档段长池 |
| `burst_run` | `[2, 3]` | 一串急闪连几张 |

> 缺省池子是从一条真实参考片逐帧量出来的（中位：慢 27 帧 / 快 5 帧，每秒 9.9 个切点）。
> **别用 `uniform(lo, hi)` 范围猜**——猜出来的中位数对不上，整体会偏慢。
> 要抄别的片子，用 `scripts/measure.py --emit-spec` 直接量成池子。

## `source`

| 字段 | 缺省 | 说明 |
|---|---|---|
| `lead` | 0.5 | 跳过素材开头多少秒。很多运镜产物头几帧几乎静止，快闪里会像卡住 |
| `stride` | 1.7 | 同一素材每次复用往后挪多少秒，保证两次出现取的不是同一段 |

> 偏移会被**自动夹在素材实际时长内**（脚本 ffprobe 取真实长度再取模）。
> 这不是保守——`ffmpeg -ss` 越界时一帧不出**且退出码为 0**，不夹紧会静默产出短片。

## `grade`

| 字段 | 缺省 | 说明 |
|---|---|---|
| `preset` | `warm-cyan` | `warm-cyan` 暖高光+青阴影洗白 / `wash` 只洗白不定色向 / `none` 不调色 |
| `rgb_shift` | 9 | 红青错位像素。6 轻 / 9 中 / 14 重 / 0 关 |
| `smear` | 2 | 拖影帧数。**要跟 `seg` 匹配**：`seg ≤ 6` 用 2，`seg ≥ 10` 或 `rhythm` 档可用 3 |

> 调色链是 `curves` 抬黑位 → `colorbalance` 定色向 → `eq` 去饱和加对比。
> **别用 `blend=screen` 拿模糊副本做泛光**——会把阴影推成品红，而故障片该是「暖高光 + 青阴影」。

## 脚本不接受的事

| 想干的 | 为什么不做 |
|---|---|
| 带内左右位移 | 参考片逐帧量过：切点全是换图、零横移。"撕裂"来自各带内容不同，位移是画蛇添足 |
| 带间转场 / 淡入淡出 | 频闪的力量来自硬切 |
| 音轨 | 产物无声，音乐音效在 NLE 里叠 |
| 自动进 `.gtrk` 工程 | `gtrk` 没有加任意视频 clip 的命令；裸手改工程 JSON 是红线。拖进客户端 |

## `measure.py`

```bash
python scripts/measure.py <video> [--bands N] [--k 1.0] [--emit-spec]
```

- 不给 `--bands` 时按峰强自动定带数；**自动检出只是省事，拿不准就显式给**。
- `--k` 是切点检测阈值 μ+kσ。**漏切就调小到 0.5**——等间隔快闪里两张不同的图
  在某条带恰好明暗接近时，差值不够大会被漏检，看起来像"这里停了一下"，
  其实产物是对的，是量法太严。
- `--emit-spec` 吐出可直接粘进 spec 的 `fps` / `bands` / `rhythm` 段。
