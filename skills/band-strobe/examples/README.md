# band-strobe 示例

两份 spec 骨架，`clips` 换成你自己的片段路径就能跑。

| 文件 | 档 | 用在 |
|---|---|---|
| [`op-uniform.spec.json`](op-uniform.spec.json) | 等间隔快闪，6 帧一张 | **片头 OP**。全画幅约 30 刀/秒，一刻不停 |
| [`flashback-rhythm.spec.json`](flashback-rhythm.spec.json) | 慢段与急闪串交替 | **片中闪回**。更"喘气"，但容易被读成「切换时停了一下」 |

```bash
python ../scripts/band_strobe.py op-uniform.spec.json --out out.mp4
```

## 两档怎么选

主理人 2026-09-21 的实际取舍：参考片用的是 `rhythm` 档，但放进自己的片子里看，
那些慢档读起来就是**「切换的时候停一下」**，于是改成了 `uniform`。

所以缺省给 `uniform` 不是因为它更"正确"，而是因为**片头要的是密度不是呼吸**。
真要做片中闪回、或者素材本身信息量大需要时间看，再上 `rhythm`。

## 挑素材

- 6–12 个，少于「带数 + 1」脚本会拒绝。
- 挑**一眼能认出来**的：人物立像、标志性物件、全片最亮的一帧。
  0.1 秒一张，观众只接收轮廓与色块。
- 片头 **MUST 避开剧透**——后半程的重场留到正片。
- 别选整段几乎不动的，快闪里会像卡住。
