# globe-arcs · spec.json 字段

> 时间单位秒，从颗粒 0 起算（= 坑位起点）。经纬度为十进制度，**北纬、东经为正**。屏幕坐标单位 px。

## 顶层

| 字段 | 必填 | 缺省 | 说明 |
|---|---|---|---|
| `id` | ✓ | — | `data-composition-id` |
| `width` / `height` | | 1920 / 1080 | 画幅。MUST 等于目标工程画幅 |
| `duration` | ✓ | — | 时间线目标总长。MUST ≥ 坑位包络 + 0.3 |
| `bg` | | `dark` | `dark` / `light` / `transparent` / `#RRGGBB` |
| `palette` | | 预设值 | 覆写配色，键见下表 |
| `fonts.sans` | | 思源栈 | 标题与地名标签字体。MUST 命中渲染服务端字体表 |
| `globe` | | 见下 | 地球的位置、大小、点径、经纬网 |
| `view` | | `{lon:0, lat:20, zoom:1}` | 0 秒时正对镜头的经纬度与缩放 |
| `spin` | | 3 | 自转速度（°/s，向东为正）。0 = 不转 |
| `views` | | `[]` | 转向 / 推近关键帧 |
| `places` | | `[]` | 地点 |
| `arcs` | | `[]` | 飞线 |
| `title` | | — | `{"title", "sub", "x", "y"}` 左上标题（缺省 x 96、y 72） |
| `safe_bottom` | | 0.85 | 字幕带上沿（画幅高比例）。地名标签不得越过 |

## `palette` 键

| 键 | dark | light | 用在 |
|---|---|---|---|
| `canvas` | `#05070C` | `#EDF0F4` | 画布底（`transparent` 预设为空） |
| `ocean` / `ocean_hi` | 深蓝 / 亮蓝 | 灰蓝 / 浅 | 海洋圆盘的底色与左上高光 |
| `atmosphere` | 半透明蓝 | 半透明灰蓝 | 地球外缘辉光（径向渐变） |
| `land` | 浅蓝 | 深灰蓝 | 陆地点阵 |
| `graticule` | 极淡 | 极淡 | 经纬网（每 30°） |
| `arc` / `head` | 琥珀 / 暖白 | 橙红 / 白 | 飞线 / 飞线亮头 |
| `ring` / `marker` | 琥珀 / 白 | 橙红 / 深 | 落点光圈与标记描边 / 标记填充 |
| `ink` / `ink_sub` | 近白 / 灰 | 深 / 灰 | 地名与标题 / 副标题 |
| `chip` | 半透明黑 | 半透明白 | 地名标签底 |

## `globe`

| 字段 | 缺省 | 说明 |
|---|---|---|
| `x` / `y` | 0.5W / 0.47H | 地球中心 |
| `radius` | min(W, H) × 0.36 | zoom = 1 时的半径 |
| `dot` | radius × 0.0042（≥ 1.2） | 陆地点半径（随 zoom 按平方根放大） |
| `graticule` | `true` | 画经纬网 |

## `views[]`

| 字段 | 必填 | 缺省 | 说明 |
|---|---|---|---|
| `t` | ✓ | — | 开始转的时刻 |
| `dur` | | 1.6 | 转动时长（power2.inOut） |
| `at` | 二选一 | — | 地点 id：转完那一刻它在正中 |
| `lon` / `lat` | 二选一 | 不变 | 转完那一刻正中的经纬度 |
| `lat_offset` | | 0 | 在目标纬度上加几度（正 = 让目标落在画面中心偏下，给下方标签留地方） |
| `zoom` | | 不变 | 转完时的缩放 |

脚本自动扣掉自转并走最短经度方向；转动段之间 MUST 不重叠，MUST 在颗粒时长内结束。

## `places[]`

| 字段 | 必填 | 缺省 | 说明 |
|---|---|---|---|
| `id` | ✓ | — | 唯一 id，飞线与视角用它引用 |
| `name` | | — | 地名标签文字；空则只画标记点 |
| `lat` / `lon` | ✓ | — | 纬度 −90..90、经度 −180..180 |
| `label` | | `right` | `right` / `left` / `above` / `below` / `none` |
| `t` | | 自动 | 出现时刻。缺省：作起点时在起飞前 0.3 s，作终点时在落地时；都不是则 0 |

地点转到背面时自动隐去（靠近边缘渐隐）。

## `arcs[]`

| 字段 | 必填 | 缺省 | 说明 |
|---|---|---|---|
| `from` / `to` | ✓ | — | 地点 id |
| `t` | ✓ | — | 起飞时刻。此刻起点 MUST 在正面 |
| `dur` | | 1.4 | 飞行时长；落地 = `t + dur`，此刻落点 MUST 在正面 |
| `style` | | `line` | `line` 常亮线 + 亮头（落地后线留着）/ `trail` 亮头拖 1/4 弧长的尾巴，落地后尾巴收进落点 |
| `height` | | 0.06 + 0.30 × 弧角 / 180° | 弧顶离地高度（地球半径的倍数） |
| `ring` | | `true` | 落地光圈 |
| `rings` | | 2 | 光圈圈数（每圈 0.9 s，有限次） |
| `color` | | `palette.arc` | 这条线的颜色 |

## 生成器 stdout 摘要

```json
{"id": "...", "chars": 14543, "duration": 11,
 "globe": {"x": 960, "y": 507.6, "radius": 388.8, "dot": 1.633, "land_points": 8265},
 "spin": 2.5,
 "views": [{"t0": 4.6, "t1": 6.4, "center_at_t1": [33.2, 55.27], "zoom": 1.08}],
 "places": [{"id": "sha", "t": 0.7, "z_at_end": 0.696}, ...],
 "arcs": [{"k": 0, "from": "sha", "to": "sin", "t": 1.0, "arrive": 2.2, "deg": 34.23, "height": 0.117,
           "z_from": 0.949, "z_to": 0.952}, ...],
 "out": "<绝对路径>"}
```

`z_from` / `z_to` 是起飞时起点、落地时落点的朝向（1 = 正对镜头，0 = 在边缘，< 0 = 背面）；`z_at_end` 是终态各地点的朝向（< 0.12 的标签不显示）。
