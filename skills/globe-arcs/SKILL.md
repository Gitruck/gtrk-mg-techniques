# globe-arcs · 点阵地球飞线

四个动作，一条时间线：

| 动作 | 画面 | 用在什么时候 |
|---|---|---|
| **自转** | 点阵地球缓慢自西向东转 | 全程打底，让画面一直「活着」 |
| **转向 / 推近** | 地球转到某座城市正对镜头，同时可放大 | 「把视线拉到欧洲」「看北美西海岸」——口播换地区的那一刻 |
| **飞线** | 两城之间飞出一道抬离地表的大圆弧：常亮线（`line`）或亮头拖尾（`trail`） | 「从上海出发」「货物运往……」「跨过太平洋」 |
| **落地** | 落点地表泛起两圈透视光圈，地名标签亮起 | 「抵达」「覆盖到」——每到一处的确认感 |

## 分工：你决定内容与节奏，脚本只做机械活

**你（agent）负责**：有哪些地点（名称、经纬度）、谁飞向谁、每条线什么时候起飞多久落地、哪一刻把哪座城市转到正面、标签放哪边。
**脚本负责**：陆地点阵、正射投影、把「t 时刻让某城居中」换算成扣除自转后的旋转补间（走最短方向）、大圆弧采样与抬高、遮挡判断、光圈几何，以及**在生成期按同一套投影复算**每个关键时刻：起点落点是否在正面、标签是否出画 / 互叠 / 压标题。

这是**技法**不是模板：脚本里没有预设航线、没有城市表、没有栏目色板。

## 工作流

### 1. 定地点

- 经纬度用十进制度，**北纬、东经为正**（南纬、西经为负）。城市坐标是公开地理数据，取市中心即可。
- 名称写你口播里的叫法；标签方向（`label`）按地理关系先给个直觉值（西边的城市放 `left`），脚本会查互叠，叠了再换。
- 一屏 **≤ 6 个**地点、**≤ 4 条**飞线；更多就拆成两颗颗粒或换数据图（地球是情绪画面，不是精确地图）。

### 2. 按口播定节奏

拿句级时码（`transcript.json` 的 `st/ed`）按字数内插，减去颗粒起点 `track_st`。经验值：

- 飞线 `t` = 口播说出起点（「从上海……」）的时刻；`dur` 1.0–2.6 s，跨洋长线给长一点。落地时刻 = `t + dur`，对准说出终点的那个词。
- 相邻两条飞线错开 ≥ 0.8 s；同时起飞会让观众不知道看哪条。
- 换地区用 `views`：`t` 是开始转的时刻，`dur` 1.4–2.0 s；`at` 写地点 id，转完那一刻它在正中（可用 `lat_offset` 往上偏几度，给下方标签留地方）。
  转向期间不要安排落地——落点会在转动中滑走。
- 最后一个动作之后至少留 0.3 s；终态是自转中的地球 + 全部飞线与标签，有限时长内持续转动即「活着」（铁律 7）。

### 3. 写 spec

字段全表见 `references/spec.md`。要点：

- `view` 是 0 秒时正对镜头的经纬度；`spin` 是自转速度（°/s，缺省 3；要静止设 0）。
- 一条飞线的起点在起飞时、落点在落地时**必须在正面**（z ≥ 0.25），否则脚本拒绝并告诉你在哪一刻转到了背面——加一个 `views` 把它转过来。
- 起点终点几乎对跖（相距 > 178°）时大圆路径不唯一，脚本拒绝——中间加一个中转地点拆成两段。
- `bg`：`dark` / `light` / `transparent` / `#RRGGBB`；栏目色用 `palette` 注入（`land` / `arc` / `ring` / `atmosphere`……）。

### 4. 生成 → lint → 验收

```bash
python scripts/globe_arcs.py <spec.json> --out <工程>/mg/<composition_id>.html
gtrk mg lint <工程>/mg/<composition_id>.html --dispatch <工程>/split/dispatch.json
python scripts/globe_check.py <工程>/mg/<composition_id>.html --out <系统temp>/sheet.png [--video <系统temp>/preview.mp4]
```

- 产物约 1.5 万字符（陆地点阵位图 5 KB）。stdout 摘要报出每条飞线起落时两端的 z（越接近 1 越正对镜头）与每个地点终态的 z。
- **首次上线 MUST 先真渲一颗**（`gtrk mg render <html> --duration <s>`）抽帧确认：本技法靠时间线 `onUpdate` 回调整帧重画 canvas。
  gsap-emit「回调与 seek 语义」规定定帧时回调可达是引擎侧义务，但本仓此前的颗粒都不依赖回调，这一条还没在真引擎上实测过。

### 5. 交回铺轨

派单模式交回 `/gtrk-mg`（`gtrk mg --project`），独立模式走 `gtrk mg render <html> --duration <s>` 出透明 MOV。

## 为什么是点阵 + canvas

- 点阵地球只需要「哪里是陆地」一份位图，就能在任意角度、任意缩放下重画——没有贴图、没有 WebGL、没有外部依赖，5 KB 进颗粒。
- 每帧整帧重画（不累加、不追加）：seek 到哪一帧画哪一帧，满足 gsap-emit「幂等回调」。
- 三层 canvas：背层（大气辉光、海洋、经纬网）、陆地层（只有点阵）、特效层（飞线、光圈、标签）。分层是为了让验收工具能单独读陆地层的像素。
- 零卷积：辉光、海洋高光、飞线亮头都是径向渐变，没有 `filter` / `shadowBlur`。

## 陆地数据的来历

`assets/land-mask.json` 由 `scripts/build_land_mask.py` 从 **Natural Earth 1:110m Land**（`ne_110m_land`，[naturalearthdata.com](https://www.naturalearthdata.com/)，**公有领域**）栅格化而来：
纬度环每 1.2° 一圈、环上每 1.2° 弧长一点，共 28 650 点、其中陆地 8 265 点；文件里记了源数据的 sha256。
平时用不到构建脚本——只有要换分辨率或换数据源时才重跑（依赖 numpy）。

1:110m 是全球尺度的概略数据：小岛会缺、海岸线是概略的。**不要用它表达领土、边界**——本技法不画国界，也不应被用来暗示任何领土主张。

## 自检（脚本当场退出、不产文件）

| 查什么 | 为什么 |
|---|---|
| 经纬度越界、地点 id 重复、飞线引用了不存在的地点 | 引用错一处，线就飞到别处 |
| 起飞时起点 / 落地时落点不在正面 | 观众看不见起落——报出是哪一刻转到了背面 |
| 起点终点几乎重合或几乎对跖 | 没有线 / 大圆路径不唯一 |
| 视角转动互相重叠、转动超出颗粒时长 | 两段旋转打架 |
| 地点标签在出现时或终态出画、进字幕带、互相叠、压到标题 | 标签是观众唯一读到的字——按估算字宽复算 |
| 名称 / 标题含 emoji | 渲染端字体表没有彩色 emoji |
| 最后一个动作离颗粒末尾不到 0.3 s | 没有驻留 |
| `palette` 键拼错；超字符预算 | 静默不生效 / 静默拒挂 |

## 验收：`globe_check.py` 的读数

| 读数 | 合格线 | 量的是什么 |
|---|---|---|
| `land.land_hit` / `land_probes` | 全中 | 14 个远离海岸的已知陆地点（撒哈拉、西伯利亚、澳洲腹地……）在正面时，按**本工具自己的投影**算出屏幕位置，去陆地层 canvas 读像素，下面必须有点阵 |
| `land.ocean_false` | 0 | 12 个大洋点下面不能有点阵 |
| `proj_err_px` | ≤ 0.75 | 本工具算的地点位置 vs 颗粒实际画的位置 |
| `arc_end_err_px` | ≤ 1 | 落地时刻飞线末端 vs 落点投影 |
| `arrive_vis` | ≥ 0.95 | 落地 0.45 s 后落点标记的可见度 |
| `labels.bad` | 空 | 终态正面标签（按**实测**字宽）出画 / 进字幕带 / 互叠 |
| `frames` | 动作期相邻不同 | 抽样帧 sha1 |

地理朝向这一项做过故障注入：把陆地点阵经度取反（地图镜像），80 个陆地探针里 38 个落空，验收判不合格。

## 这个技法**不做**什么

- **不画国界、行政区、领土**：只有陆地 / 海洋两态的点阵。
- **不画真实航线 / 实时数据**：飞线是两点间的大圆示意，不代表任何真实运营线路；涉及真实业务时在标题或副标题写明「示意」。
- **不做贴图写实地球**：没有卫星图、没有昼夜、没有云层。

## 硬约束（不满足别交付）

1. gsap-emit v1 全部铁律——脚本已按此发射；画面全部由时间线状态驱动，`onUpdate` 整帧重画、幂等。
2. 零卷积：没有 `filter` / `shadowBlur` / `feGaussianBlur`。
3. 字体名命中渲染服务端字体表；缺省思源栈已命中（标签用 canvas `fillText`，同一字体栈）。
4. 画幅 = 目标工程画幅；竖屏工程另写一份 spec（`globe.x / y / radius` 按新画幅给）。
5. 首次上线先真渲一颗抽帧（见上「验收」）；线路是示意时写明「示意」。
