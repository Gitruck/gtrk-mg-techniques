# lyric-pv · 文字 PV（歌词排版）

一句歌词 = 一个镜头 = 七类部件的组合：

| 类 | 可选 | 决定了什么 |
|---|---|---|
| **布局** `layout` | `center` 居中 · `stack` 叠排（左起、逐行缩进）· `vertical` 竖排 · `split` 对角分置 · `band` 斜色带 · `scatter` 散排（字号各异、上下起伏）· `frame` 框 · `ticker` 跑马灯 | 字在画面的哪里、长什么阵型 |
| **登场** `enter` | `rise` 升起 · `pop` 弹出 · `wipe` 擦入 · `type` 打字 · `scramble` 乱码定字 · `drop` 落下 · `zoom` 冲入 · `part` 两侧合拢 | 这句怎么出来 |
| **停留** `hold` | `drift` 缓推 · `still` 静止 · `float` 漂浮 · `tilt` 倾斜 | 唱这句的时候画面怎么「活着」 |
| **退场** `exit` | `fade` · `cut` · `wipe` · `scatter` 飞散 · `sink` 沉落 · `stretch` 拉扁 | 这句怎么走（最后一句不退场，驻留到底） |
| **装饰** `decor` | `marks` 角标 · `rule` 上下线 · `circle` 圆 · `slash` 斜线 · `dots` 点列 · `bigno` 大编号 · `index` 编号与时码 | 0–2 个，给版面一点「设计感」 |
| **转场** `transition` | `none` · `flash` 闪白 · `wipe` 色块擦过 | 句与句之间 |
| **背景** | 预设底色 + 段落（`part`）切换时换底；`stripes` / `grid` 底纹缓移 | 段落感 |

外加两条全局的：**作画节奏** `koma`（1 逐帧 / 2 一拍二，每秒 12 张 / 3 一拍三，每秒 8 张——文字 PV 那种一顿一顿的动作），
**配色** `style`（`ink` 墨底 / `paper` 纸色衬线 / `mono` 白底 / `transparent` 透明叠加）。

思路来自 JIZURA（文字 PV 自动构成，MIT）：它把表现拆成布局 / 登场 / 保持 / 退场 / 装饰 / 背景 / 镜头 / 转场几类部件，
每句各取一个组合起来，种子不同构成就不同。本 skill 借了这个分类和「副歌回到原样」「相邻不重复」几条构成规则，部件全部自写。

## 分工：你决定歌词、节奏与重点，脚本只做机械活

**你（agent）负责**：歌词与时码、在哪里断行（`|`）、哪句的哪个词是重点（`emph`）、哪几句点名用什么部件、段落怎么分（`part`）、整体用哪套配色和作画节奏。
**脚本负责**：估字宽定字号、断行（没给 `|` 时按字数均分）、排每个字的位置、按 seed 抽选没点名的部件、发射时间线、自检。

这是**技法**不是模板：脚本里没有歌词、没有栏目色板。同一份脚本、同一首歌换个 seed 就是另一版构成。

## 工作流

### 1. 拿歌词与时码

- **LRC**：`"lrc": "song.lrc"`（`[mm:ss.xx]歌词`，一行多个时间标签也认）。要给某几句点名部件，用 `line_overrides`（按 LRC 行序）。
- **JSON**：`"lines": [{"t": 0.4, "text": "……"}, ...]`。`end` 不给就到下一句开始。
- 时码一律是**颗粒时间**（从这颗粒的第 0 秒算）；歌在工程里从别处开始，就把时码整体减掉。
- 只用你有权使用的歌词：自己的歌、授权的歌、或原创示意文字。

### 2. 断行与重点（最影响观感的一步）

- 脚本**不做中文分词**，按字数均分会拆开词（「凌晨四 / 点的街灯」）。要断行就在歌词里写 `|`：`凌晨四点|的街灯`。显示时 `|` 去掉。
- `emph` 写这句里**真正的重点词**（逐字匹配）：放大 1.55 倍、换成强调色。带强调词的句子只会抽到支持强调的布局（不会抽到色带、跑马灯）。
- 一句太长时脚本先缩字号、再拆行（最多 3 行）；缩到 `min_font_size` 还放不下就拒绝——拆成两句。

### 3. 定构成

- **先全部交给 seed**，看接触表，再对不满意的那几句点名 `layout` / `enter` / `exit` / `decor`。点名的部件优先，其余仍按 seed 抽。
- 用 `layouts` / `enters` / `exits` / `decors` 收窄抽选范围，定下整首的调子（抒情歌别抽 `scatter` 退场和 `pop` 登场）。
- 同一句歌词再出现（副歌）会回到第一次的样子——这是有意的，观众会认出「这句又来了」。不想要就在那句点名部件。
- 段落用 `part`：从某句起写 `"part": 1`，之后的句子沿用；段落切换时底色换成 `bg_alt`。
- `koma: 2`（缺省）是文字 PV 的味道；抒情慢歌、竖屏短视频想要顺滑就用 `koma: 1`。

### 4. 生成 → lint → 验收

```bash
python scripts/lyric_pv.py <spec.json> --out <工程>/mg/<composition_id>.html
gtrk mg lint <工程>/mg/<composition_id>.html --dispatch <工程>/split/dispatch.json
python scripts/lyric_check.py <工程>/mg/<composition_id>.html --out <系统temp>/sheet.png [--video <系统temp>/preview.mp4]
```

- stdout 摘要逐句报出抽到的布局、登场、停留、退场、装饰、转场、字号、是不是副歌复现——**拿它对着接触表改 spec**。
- 产物 1–2 万字符（纯文字）。lint 的 `x-soft-alpha` 是信息项。
- **预检不是验收**：真验收 = 真渲染引擎抽帧（`gtrk mg render` / `gtrk render`）。

### 5. 交回铺轨

派单模式交回 `/gtrk-mg`（`gtrk mg --project`），独立模式走 `gtrk mg render <html> --duration <s>` 出透明 MOV（`style: transparent` 时字带描边，叠在画面上也读得清）。

## 自检（脚本当场退出、不产文件）

| 查什么 | 为什么 |
|---|---|
| 时码不严格递增、越出时长 | 顺序乱了、句子出不来 |
| 一句在屏上不到 0.3 s，或读速 > `max_cps`（缺省 20 字/秒） | 读不完——拆句或并句 |
| 一句缩到最小字号、拆三行仍放不下；用 `\|` 指定的某一行最小字号也放不下 | 放不下就别硬塞 |
| 任何一个字排出安全框（跑马灯除外） | 出画的字等于没写 |
| `emph` 在这句里找不到；带强调词却点名了色带 / 跑马灯 | 改了歌词忘改重点；这两种布局整行同字号 |
| emoji；部件名、配色键、`style`、`koma` 不认识；LRC 找不到 | 豆腐块；拼错会静默不生效 |
| 超字符预算 | 客户端静默拒挂 |

## 验收：`lyric_check.py` 的读数

| 读数 | 合格线 | 量的是什么 |
|---|---|---|
| `ink_min` / `ink_median` | 逐字 ≥ 0.008、整句中位 ≥ 0.04 | 停留中段**截图**里，每个字框内接近该字颜色的像素占比。字被裁掉、被盖住、透明都会掉到 0 |
| `overlap_max` | ≤ 0.25 | 字框两两相交面积 / 较小字框（散排、强调放大最容易压字） |
| `out_of_frame` | 0 | 排出画幅的字（跑马灯不算） |
| `text_ok` | true | 显示出来的字（去掉乱码干扰字）连起来等于歌词原文 |
| `before` / `done` / `after` | 0 / 1 / 0 | 起点前 0.04 s 这句的不透明度、登场结束时显出来的字比例、终点后 0.03 s 的不透明度 |

为什么必须看像素：开发时出过一个 bug——装字的容器高度为 0，`wipe` 登场的 `clip-path` 把整句裁没了，
而 DOM 里每个字的位置、不透明度都正常，只读 DOM 的检查全部通过。故障注入：把这个 bug 放回去，`ink_min` 0.000，判不合格。

## 这个技法**不做**什么

- **不对歌词打时间轴**：时码由调用方给（LRC、或口播 / 歌声转写的句级时码）。
- **不做逐字卡拉 OK 染色**：一句是一个镜头；逐字高亮字幕用客户端目录里的字幕类技法。
- **不做和风 / 恐怖等题材部件**（提灯、障子、监视器……）：那些是 JIZURA 的特色题材，这里只留通用的版式部件。
- **不配音**。

## 硬约束（不满足别交付）

1. gsap-emit v1 全部铁律——脚本已按此发射；乱码定字、打字都是时间线上的 set / stagger，不用回调。
2. 零卷积：没有 `filter: blur()`；透明叠加的描边用 `-webkit-text-stroke`，不用 `text-shadow` 模糊。
3. 字体名命中渲染服务端字体表；缺省思源黑体 / 思源宋体栈已命中。
4. 画幅 = 目标工程画幅；竖屏工程直接改 `width` / `height`，版面按画幅重排。
5. 歌词只用你有权使用的；示例歌词是原创示意文字。
