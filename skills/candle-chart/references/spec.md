# candle-chart · spec.json 字段

> 时间单位秒，从颗粒 0 起算（= 坑位起点）。坐标单位 px。
> 蜡烛的位置**不用给**：脚本按根数等分版面宽度、按纵轴范围换算高度；你只给数据、动作与时刻。
> 引用某一根时，`at` / `from` / `to` / `slice` 既可以写**日期**（逐字匹配数据的日期列），也可以写**下标**（0 起）。

## 顶层

| 字段 | 必填 | 缺省 | 说明 |
|---|---|---|---|
| `id` | ✓ | — | `data-composition-id` |
| `width` / `height` | | 1920 / 1080 | 画幅。MUST 等于目标工程画幅 |
| `duration` | ✓ | — | 时间线目标总长。MUST ≥ 坑位包络 + 0.3 |
| `bg` | | `dark` | `dark` / `light` / `transparent` / `#RRGGBB` |
| `convention` | | `cn` | `cn` 红涨绿跌 / `us` 绿涨红跌（交换 `up` / `down` 两色） |
| `palette` | | 预设值 | 覆写配色，键见下表 |
| `fonts.sans` | | 思源栈 | 全图字体。MUST 命中渲染服务端字体表 |
| `csv` | 二选一 | — | CSV 路径（相对 spec 或绝对）。表头见下 |
| `data` | 二选一 | — | 内联数据：`[[日期, 开, 高, 低, 收, 量?], ...]` 或 `[{"d","o","h","l","c","v"}, ...]` |
| `slice` | | — | `[起, 止]`（含两端），先截取再合并 |
| `aggregate` | | 1 | 每 N 根合并成一根（开 = 首根开、高 = 最高、低 = 最低、收 = 末根收、量 = 求和；日期 = 首根日期） |
| `volume` | | `true` | 画成交量副图（数据没有量列时自动不画；显式 `true` 而缺量列会报错） |
| `layout` | | 见下 | 版面 |
| `body` | | 0.62 | 实体宽占每根槽位的比例 |
| `decimals` | | 自动 | 价签与标注的小数位。缺省取数据里出现的最大小数位（≤ 4） |
| `y_range` | | 自动 | `[下限, 上限]`。不给时取数据 ±8%，再按标注需要放宽头顶 / 脚下 |
| `ticks` | | 5 | 期望刻度数（实际取 1 / 2 / 2.5 / 5 × 10ⁿ 里最接近的步长） |
| `date_labels` | | 6 | 底部日期标签个数（等距取） |
| `grow` | | 见下 | 生长时间窗 |
| `ma` | | `[5, 20]` | 均线周期列表；或 `{"periods": [...], "at": 秒, "dur": 秒}` 改成长完后单独描出；`[]` 不画 |
| `marks` | | `[]` | 点位标注 |
| `levels` | | `[]` | 水平价位线 |
| `ranges` | | `[]` | 区间高亮 |
| `header` | | — | `{"title", "sub"}` 左上标题与副标题（副标题放来源 / 口径 / 「合成数据」） |
| `last_tag` | | `true` | 生长结束后在右轴挂最新收盘价签 |
| `label_size` | | 22 | 标注标签字号 |
| `intro` | | 0.1 | 坐标轴与标题淡入的时刻 |
| `safe_bottom` | | 0.85 | 字幕带上沿（画幅高比例）。日期标签与标注都不得越过 |

### CSV 表头

| 列 | 认这些表头（不分大小写） |
|---|---|
| 日期 | `date` / `d` / `time` / `日期` / `时间` |
| 开 | `open` / `o` / `开盘` / `开盘价` |
| 高 | `high` / `h` / `最高` / `最高价` |
| 低 | `low` / `l` / `最低` / `最低价` |
| 收 | `close` / `c` / `收盘` / `收盘价` |
| 量（可无） | `volume` / `v` / `vol` / `成交量` |

## `palette` 键

| 键 | dark | light | 用在 |
|---|---|---|---|
| `canvas` | `#0E1014` | `#F6F6F4` | 画布底（`transparent` 预设为空） |
| `grid` / `axis` | 浅线 / 灰 | 浅线 / 灰 | 网格线 / 刻度与日期文字 |
| `ink` / `ink_sub` | 近白 / 灰 | 近黑 / 灰 | 标题与标签字 / 副标题与图例 |
| `up` / `down` | 红 / 绿 | 红 / 绿 | 涨 / 跌（`convention: us` 时两色互换后再应用 palette） |
| `accent` | 琥珀 | 琥珀 | 标注点、引线、区间文字 |
| `band` | 半透明琥珀 | 半透明琥珀 | 区间高亮底 |
| `chip` / `chip_line` | 深底 / 浅边 | 白底 / 浅边 | 标注标签底与描边 |
| `level` | 灰 | 深灰 | 价位线与价签 |
| `ma` | 4 色列表 | 4 色列表 | 均线颜色，按周期顺序轮换 |

## `layout`

| 字段 | 缺省 | 说明 |
|---|---|---|
| `x` / `y` | 120 / 150 | 价格区左上角 |
| `w` | 画幅宽 − 360 | 价格区宽（右侧留 240 给刻度与价签） |
| `h` | 到字幕带上沿 − 38 | 价格区 + 成交量区的总高 |
| `volume_h` | 总高 × 0.2 | 成交量区高（与价格区隔 20px） |

## `grow`

| 字段 | 缺省 | 说明 |
|---|---|---|
| `start` | 0.6 | 第一根开始长 |
| `end` | min(duration × 0.55, start + 6) | 最后一根长完 |

每根的生长时长 = clamp(窗口 / 根数 × 4, 0.12, 0.45) s，相邻两根错开等间隔。stdout 摘要 `grow` 报出 `step`（错开间隔）与 `candle_dur`。

## `marks[]`

| 字段 | 必填 | 缺省 | 说明 |
|---|---|---|---|
| `at` | ✓ | — | 哪一根（日期或下标） |
| `kind` | | `high` | `high` 最高价 / `low` 最低价 / `close` 收盘价 / `price` 任意价位（配 `price`） |
| `price` | `price` ✓ | — | `kind: price` 时的价位 |
| `side` | | `low` 在下，其余在上 | `above` / `below`：标签放在这根影线的上方 / 下方 |
| `text` | | 价位数字 | 标签文字。里面出现与价位同精度的小数时 MUST 等于实际价位 |
| `t` | | 那根长完 + 0.2 | 落下时刻。MUST ≥ 那根长完 |

## `levels[]`

| 字段 | 必填 | 缺省 | 说明 |
|---|---|---|---|
| `price` | ✓ | — | 价位。MUST 在纵轴范围内 |
| `t` | | 生长结束 + 0.3 | 从左划到右的时刻（0.7 s），右端价签随后亮起 |
| `text` | | — | 线左端上方的小字（「支撑」「前高」） |
| `style` | | `dashed` | `dashed` / `solid` |

## `ranges[]`

| 字段 | 必填 | 缺省 | 说明 |
|---|---|---|---|
| `from` / `to` | ✓ | — | 区间首尾两根（含两端） |
| `t` | | 末根长完 + 0.2 | 亮起时刻。MUST ≥ 末根长完 |
| `text` | | — | 区间顶部的文字（「回撤 −37.7%」——数自己算对） |

## 生成器 stdout 摘要

```json
{"id": "...", "chars": 47526, "duration": 14, "candles": 120, "first": "2025-03-03", "last": "2025-08-15",
 "plot": {"x": 120, "y": 150, "w": 1560, "h": 564, "volume_h": 146},
 "y_range": [28.47, 56.39], "ticks": ["30", "35", "40", "45", "50", "55"],
 "grow": {"start": 0.6, "step": 0.04874, "candle_dur": 0.2, "end": 6.6},
 "ma": [5, 20], "ma_done": 6.6,
 "marks": [{"k": 0, "at": "2025-04-14", "kind": "high", "price": 52.28, "t": 7.2, "covers": 0}],
 "levels": [...], "ranges": [...], "hold_from": 12.2,
 "extremes": {"max_high": ["2025-04-14", 52.28], "min_low": ["2025-06-30", 32.58],
              "max_close": [...], "min_close": [...], "first_open": [...], "last_close": [...]},
 "out": "<绝对路径>"}
```

`covers` 是该标注的标签盖住的蜡烛根数（不算错，但 > 0 多半该换 `side`）；`extremes` 是标签取数的来源。
